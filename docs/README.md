# Docs

Канон. Не дублировать одно и то же в трёх файлах — править источник.

| Файл | Роль |
|---|---|
| `spec-poisk-zhivotnyh.md` | Продукт целиком: роли, сценарии, модель данных, механика трека, этапы, открытые вопросы |
| `status.md` | Курсор смены: ветка, Now, Next, как продолжить. Перезаписывать |
| `handoff.md` | Протокол старта/конца сессии, что куда писать, шаблоны |
| `git-workflow.md` | Ветки, PR, squash, когда появится `develop` |
| `versioning.md` | Semver: `VERSION`, changelog, когда бампать |
| `sessions/` | Заметки сессий: что сделали и **почему** |
| `decisions/` | Решения, которые ограничивают будущую работу (ADR) |

Корневой `AGENTS.md` — инварианты для агентов и правила работы в репо.
Он не заменяет спеку.
