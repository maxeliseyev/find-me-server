# 2026-09-09 — механические гарантии контракта

## Context

Контракт (`AGENTS.md`, ADR, ветвление) появился в PR #1, но частью правил
оставался текст: инварианты нужно было прочитать и не забыть, проверки
гонялись только в CI, старт смены был ритуалом «не забудь открыть три файла».
Владелец попросил включить весь предложенный список улучшений.

## What

- `tests/test_invariants.py` — инварианты 1, 2, 3, 6, 7 как тесты с номером
  в имени; правило внесено в `AGENTS.md` (раздел «Тесты» и DoD).
- `scripts/git-hooks/pre-push` — `make check` до отправки ветки.
- `scripts/session_start.py` + `make session-start`.
- `.github/dependabot.yml` — экшены и `uv.lock` раз в месяц, двумя группами.
- Ruleset на `main` дополнен required status checks: `lint`, `test`, `contract`.
- `VERSION` 0.1.1, `CHANGELOG.md`, `docs/status.md`.

## Why

- **Инварианты тестами.** Текст, который агент читает в начале сессии,
  конкурирует с задачей; падающий тест — нет. Проверено мутацией: убрал `seed`
  в `LostReport.public_geog` — тест на детерминированность смещения упал,
  остальные шесть остались зелёными. Инвариант без реализации (фан-аут, EXIF,
  веса) тест не получает авансом: он приходит вместе с кодом, иначе `xfail`
  превращается в шум, который перестают читать.
- **pre-push, а не pre-commit, для тяжёлых проверок.** Коммитов за сессию
  десятки, пушей единицы; вешать pytest на каждый коммит — гарантированный
  `--no-verify` через неделю. Тесты пропускаются, если PostGIS не поднят:
  хук, который блокирует push из-за не запущенного докера, обходят целиком,
  вместе с полезной частью.
- **Required checks без bypass-акторов.** Обход у ruleset не настроен намеренно
  (см. `decisions/git-trunk-until-v1.md`); цена — при инфраструктурном сбое CI
  мерж чинится правкой ruleset в настройках, а не «просто пушем в main».
  Включено после того, как CI отработал зелёным на PR #1: раньше контексты
  проверок не существовали и правило заблокировало бы первый же PR.
- **Dependabot месячный, а не еженедельный.** Недельный ритм на проекте без
  пользователей превращается в фоновый шум, который перестают читать.
  Django ограничен `<5.3` в `pyproject.toml`: LTS-линия меняется осознанно.
