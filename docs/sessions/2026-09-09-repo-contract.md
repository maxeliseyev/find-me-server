# 2026-09-09 — контракт репозитория и правила ветвления

## Context

Скелет проекта был слит в `main` прямым пушем: правил в репозитории ещё не
существовало. Владелец попросил зафиксировать контракт по образцу проекта
`beat-equalizer` и запретить коммиты в `main`.

## What

- `AGENTS.md`: 18 инвариантов, выведенных из спеки (анонимная отметка, точная
  точка не публикуется, EXIF, timestamptz, веса, тихие часы, Celery, модерация),
  плюс команды, дерево, DoD и протокол смены.
- `docs/`: `handoff.md`, `git-workflow.md`, `versioning.md`, `README.md`,
  `status.md`, `decisions/` (5 ADR), `sessions/`.
- `VERSION` 0.1.0, `CHANGELOG.md` в формате Keep a Changelog.
- Механика вместо деклараций: GitHub ruleset на `main`, pre-commit хук,
  CI (ruff, pytest на живом PostGIS, `makemigrations --check`,
  `check_status.py`, `check_env_example.py`), шаблон PR с DoD-чеклистом.
- `CLAUDE.md` — симлинк на `AGENTS.md`, чтобы Claude Code подхватывал контракт
  автоматически и он не разъезжался с основным файлом.

## Why

- **Ruleset, а не только текст в AGENTS.** Текстовое правило нарушается ровно
  тогда, когда его цена выше нуля («тут же мелкая правка»). Механический запрет
  стоит один раз. ADR: `decisions/git-trunk-until-v1.md`.
- **Хук + ruleset вместе.** Ruleset ловит на пуше, когда коммит уже в истории
  и его надо переносить; хук ловит до коммита. Дешевле поймать раньше.
- **Проверки контракта в CI.** `status.md` — самый быстро протухающий файл при
  работе агентов, а забытая переменная окружения ломает не автора, а
  следующего клонирующего. Обе проверки — три десятка строк, обе окупились
  сразу: `check_env_example.py` на первом же запуске нашёл три пропущенные
  переменные.
- **ADR на уже принятые решения спеки** (первичность отметки, смещение точки,
  Telegram как транспорт, Django вместо FastAPI). Это решения, которые агент
  «оптимизирует» первым делом, не зная контекста: обязательная авторизация
  выглядит как улучшение безопасности, случайное смещение на каждый запрос —
  как улучшение приватности, хотя оно её ухудшает.
- **Self-merge разрешён** с пометкой в описании: один разработчик с
  обязательным ревью заблокирует сам себя.
