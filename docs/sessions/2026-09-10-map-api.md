# 2026-09-10 — API карты

## Context

Следующий шаг этапа 1 после API постановки отметки — карта с объявлениями и
наблюдениями. Спека требует кластеризацию на сервере.

## What

- `GET /api/v1/map/` принимает bbox и zoom, возвращает GeoJSON
  `FeatureCollection` с активными объявлениями и видимыми отметками.
- Объявления сериализуются только через `public_geog`; точная координата не
  передаётся в свойствах feature.
- Близкие точки собираются сервером в ячейки Web Mercator размером 64 px;
  кластер содержит общее число точек и отдельные числа объявлений и отметок.
- Добавлены тесты выдачи карты и инвариант 3 на уровне публичного API.

## Why

- **GeoJSON на выходе.** MapLibre принимает этот формат напрямую, поэтому
  клиенту не нужно пересобирать координаты из API-полей.
- **Кластер по экранным пикселям.** Градусная сетка меняет визуальный размер с
  широтой и zoom. Ячейка Web Mercator имеет стабильный размер на экране без
  хардкода района пилота.
- **Объявления и отметки в одном кластере.** На обзорном масштабе пользователю
  важна плотность событий; `counts` сохраняет различие сущностей для подписи и
  перехода к деталям.
