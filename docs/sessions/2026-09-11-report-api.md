# 2026-09-11 — API создания объявления

## Context

После карты и API отметки владелец должен уметь создать активное объявление,
иначе в карте могут появляться только записи из админки.

## What

- `POST /api/v1/reports/` создаёт животное и активное объявление одной
  транзакцией для авторизованного, незабаненного владельца.
- В ответе создатель получает точную точку, а в публичной карте объявление
  продолжает идти через `public_geog`.
- Добавлены тесты API и инвариант 5: телефон не попадает в ответ.

## Why

- **Животное вложено в запрос.** Первый случай пропажи не требует отдельного
  предварительного вызова для создания питомца; один запрос создаёт связанную
  пару данных атомарно.
- **Точная точка доступна создателю.** Он уже владелец записи; публичный
  endpoint карты применяет отдельное правило приватности.
- **Фото отложены.** Приём фото без срезки EXIF нарушил бы инвариант 4.
  Загрузка придёт отдельным шагом вместе с безопасной обработкой.
