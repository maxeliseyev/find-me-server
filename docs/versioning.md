# Версии

Semver: `major.minor.patch`. Один файл — `VERSION` в корне.
Не дублировать номер по коду; нужен в рантайме — читать файл.

## Что бампать

Пока `0.x` (до запуска на пилотном районе):

| Бамп | Когда |
|---|---|
| **patch** (`0.1.1`) | Документация, CI, сборка, баг без нового поведения |
| **minor** (`0.2.0`) | Новое поведение: API отметок, фан-аут, зона поиска, бот |
| **major** (`1.0.0`) | Первый запуск на реальном районе. Дальше появляется `develop` |

После `1.0.0`: major = ломающий контракт (формат API, схема данных),
minor = функция, patch = фикс.

## Как

В том же PR, что и изменение:

1. Правка `VERSION`.
2. Запись в `CHANGELOG.md` сверху.
3. Тег `vX.Y.Z` — на `main` после merge и только когда сборку реально
   разворачивают, не на каждый merge.

`make version` печатает текущий номер.
