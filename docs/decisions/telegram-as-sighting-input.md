# Telegram-бот принимает отметки о наблюдениях

Status: accepted
Date: 2026-09-10

## Context

Очевидцу важен короткий путь до сохранения отметки. Telegram уже выбран
транспортом уведомлений и даёт идентификатор пользователя, а его кнопка
геолокации точнее свободного текстового адреса.

## Decision

- Бот принимает отметку через пошаговый сценарий: геолокация, фото, вид и
  окрас, необязательный комментарий.
- Источник координат ранжируется так: `telegram_location`, `device_gps`,
  `manual_pin`, `text_address`.
- Бот использует Redis-backed FSM и буферизует фотоальбомы по `media_group_id`.
- Веб и Telegram Mini App остаются двумя входами в одну карту и общую доменную
  логику, а не отдельными продуктами.

## Alternatives

- **Только веб-форма.** Лишает пользователя самого короткого канала с живой
  геолокацией и осмысленной идентификацией.
- **Текстовый адрес по умолчанию.** Геокодирование ошибается и не равно живым
  координатам; адрес остаётся запасным вариантом с меньшим весом.
- **Опираться на EXIF Telegram-фото.** Сжатые `message.photo` обычно уже не
  содержат EXIF; координаты надо получать отдельной кнопкой.

## Consequences

- Модель отметки получит источники `telegram_location` и `text_address`, канал
  поступления и отображаемый геокодированный адрес отдельным изменением схемы.
- При реализации бота обязательны FSM, лимитирование по `telegram_id` и
  обработка альбомов.
