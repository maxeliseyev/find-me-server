# Decisions (ADR)

Сюда попадает решение, которое **ограничивает будущую работу**: его будут
переоткрывать, и без записи оно переоткроется неправильно.

Не ADR: как сделали одну задачу (это session note), выбор имени переменной,
временный обход.

Файл — `<slug>.md`, шаблон:

```markdown
# <Решение одной строкой>

Status: accepted | superseded by <slug>
Date: YYYY-MM-DD

## Context
Что заставило решать. Факты, не пересказ спеки.

## Decision
Что именно принято. Императивно.

## Alternatives
Что рассматривали и почему отвергли. Без этой секции ADR бесполезен.

## Consequences
Что теперь нельзя, что придётся поддерживать, когда пересматривать.
```

Решение, которое отменяет прежнее, не удаляет файл: старому проставляется
`Status: superseded by <slug>`.
