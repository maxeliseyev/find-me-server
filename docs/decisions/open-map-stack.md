# Карта и геокодинг используют открытый стек

Status: accepted
Date: 2026-09-10

## Context

Карта нужна с первого этапа, но пилот не должен зависеть от ключей, лимитов и
тарифов проприетарного поставщика. Для постановки точки и понятной подписи
места нужен отдельный геокодер; публичный Nominatim не разрешает автодополнение.

## Decision

- Для прототипа использовать публичный OpenFreeMap с MapLibre GL JS.
- Перед production перейти на городской PMTiles-экстракт Protomaps в своём
  объектном хранилище; клиент читает его через `pmtiles://`.
- Развернуть Photon на региональном PBF-экстракте для поиска и обратного
  геокодинга. До выбора района проверить полноту OSM: номера домов и контуры.

## Alternatives

- **Яндекс, 2ГИС, Google.** Ключи, лимиты, риск счёта и зависимость от условий
  поставщика не подходят для пилота и офлайн-сценария.
- **Публичный Nominatim.** Его политика не допускает нужный автокомплит.
- **Сразу собственный тайл-сервер.** Лишняя эксплуатационная нагрузка для
  прототипа; PMTiles решает production-задачу без постоянного сервера тайлов.

## Consequences

- Интерфейс карты строится вокруг MapLibre и открытых форматов стилей.
- Нужна корректная OSM-атрибуция и CORS для хранилища PMTiles.
- Качество OSM в районе пилота становится критерием готовности запуска.
